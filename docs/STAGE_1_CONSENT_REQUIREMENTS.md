# Stage 1 Consent Requirements

## Что нужно в стадии 1

- Перед загрузкой постановления пользователь должен подтвердить согласие на обработку персональных данных.
- Кнопки выбора: `Согласен` и `Не согласен`.
- Без согласия бот не принимает документ.
- Согласие сохраняется в базе с временем принятия, Telegram ID и версией текста.

## Какие данные обрабатываются

- Telegram ID.
- Telegram name / username.
- Постановление о штрафе.
- Документы дела.

## Цель обработки

- Создание и ведение дела по оспариванию штрафа.

## Принцип хранения

- Telegram используется только как интерфейс.
- Основные данные дела и документы хранятся в серверной инфраструктуре сервиса.
- Для текущего режима на Vercel допустимо временно хранить `telegram_file_id`.
- Этот режим считается временным до появления отдельного файлового хранилища.

## Что не делать на этапе 1

- Не добавлять OCR.
- Не добавлять автоматический юридический анализ.
- Не добавлять генерацию жалобы.
- Не добавлять интеграции с государственными системами.
