# Инструкция для пользователя

## Как войти

1. Откройте Telegram.
2. Найдите тестового бота `@shtraf_osporit_bot`.
3. Нажмите **Start** или отправьте команду `/start`.
4. Ознакомьтесь с текстом согласия на обработку данных.
5. После подтверждения бот создаст профиль и покажет главное меню.

## Как создать дело

1. Нажмите **Оспорить штраф**.
2. Отправьте постановление о штрафе:
   - PDF-файлом;
   - фотографией;
   - изображением JPG, JPEG или PNG.
3. Дождитесь сообщения о загрузке и распознавании документа.

После загрузки документ будет привязан к новому делу. При настроенном OCR бот
извлечёт основные данные постановления; если OCR не сработает, документ останется
доступен оператору для ручного заполнения.

## Как посмотреть свои дела

1. Нажмите **Мои дела**.
2. Выберите нужное дело.
3. Бот покажет:
   - номер дела;
   - текущий статус;
   - дату создания;
   - количество документов;
   - названия загруженных документов;
   - статус распознавания;
   - распознанные и подтверждённые поля постановления.

## Статусы дела

- **Документ загружен** — постановление получено системой.
- **Документ в работе** — дело обрабатывается.
- **Готов** — работа по текущему этапу завершена.

## Помощь

Нажмите **Помощь**, чтобы получить краткую информацию о доступных возможностях.

## Удаление профиля и дел

Отправьте команду `/restart`, чтобы удалить свой профиль, согласия и дела из
базы данных. После этого отправьте `/start`, чтобы начать заново.

## Важно

На текущем этапе бот сохраняет документы, выполняет OCR, извлекает основные поля
постановления и показывает заполненную карточку дела. Оператор может сверить
исходный текст и вручную исправить поля в админке.

Юридический анализ, оценка перспективности и генерация жалобы пока не выполняются.

## Согласие

Перед загрузкой постановления бот показывает краткий текст согласия. Без
подтверждения документ не принимается и дело не создается.
