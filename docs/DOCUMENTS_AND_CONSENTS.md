# Документы и согласия

## Какие данные собираем

- Telegram ID.
- Telegram name и username.
- Постановление о штрафе.
- Документы дела.
- Факт и версия согласия на обработку персональных данных.

Перед загрузкой пользователю предлагается самостоятельно закрыть или удалить
персональные данные, которые не нужны для проверки штрафа. Затем пользователь
открывает полный текст, отдельно отмечает ознакомление и подписание согласия и
подтверждает выбор. Без прохождения этих шагов загрузка недоступна.

## Зачем собираем

- Чтобы создать и вести дело по оспариванию штрафа.
- Чтобы показать историю загруженных документов.
- Чтобы дать администратору возможность сопровождать дело.

## Где храним

- Основные данные дела хранятся в серверной инфраструктуре сервиса и базе данных.
- Telegram используется только как интерфейс загрузки.
- В production документы сохраняются локально на VPS и доступны только через защищённую админку.
- Для OCR документ может передаваться OCR.space; для юридического анализа
  распознанный текст и данные дела могут передаваться DeepSeek.

## Кто имеет доступ

- Пользователь видит только свои дела.
- Администратор видит пользователей, дела и документы через админку.
- Администратор может изменить статус дела и удалить дело вместе со связанными документами.

## Как удалить

- Дело можно удалить из админки.
- При удалении удаляются связанные документы и локальные файлы, если они сохранены на сервере.
- При удалении профиля история его согласий также удаляется.
- Пользователь может отправить `/restart`, чтобы удалить свой профиль, согласия и все связанные дела из базы данных.

Текущая система выполняет удаление из основной PostgreSQL и локального файлового
хранилища. Отдельный неизменяемый журнал удаления и подтверждённое удаление из
резервных копий пока не реализованы, поэтому обещать пользователю формальное
доказательство полного уничтожения данных нельзя.

Перед коммерческим запуском в текст согласия необходимо добавить полное
наименование или ФИО реального Оператора, его адрес и действующие контакты для
отзыва согласия. Название чат-бота само по себе не идентифицирует Оператора.
